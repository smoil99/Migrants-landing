# rabota-landing

Прототип лендинга «Специалисты из Индии для бизнеса — Работа.ру».

- `site-reg/` — актуальная версия сайта (стиль reg.ru, видео на первом экране, демо «5 шагов»). Открывать `site-reg/index.html`.
- `site/` — исходная статичная копия страницы rabota-landing-poc.vercel.app (без темы).

Локальный просмотр:

```bash
cd site-reg && python3 -m http.server 8766
```

затем http://localhost:8766
