# Лендинг в стиле reg.ru

Копия статичной страницы из `../site` с новой темой.

- `index.html` — та же разметка, подключён `theme-reg.css`
- `styles.css` — исходные стили (сетка, размеры, адаптив); в конце добавлено правило для `[hidden]`
- `script.js` — интерактив (тот же, что в `../site`). Заявка никуда не отправляется,
  пока не задан `LEAD_ENDPOINT` в начале скрипта
- `theme-reg.css` — тема: шрифт Geologica, палитра reg.ru (тёмный #2b2f33, акцент #11d5cb,
  серые поверхности #f2f4f7), скругления 8/16/24/40px, тёмные и бирюзовые плашки секций.
  Все цвета вынесены в переменные `--reg-*` в начале файла.
- `flow-demo.js` — блок «От заявки до выхода на работу — 5 шагов». Шаг 1 — экран формы заявки:
  20 полей заполняются за 5 секунд, страница прокручивается, курсор жмёт «Отправить заявку», открывается окно «Готово».
  Шаги 2–5 — рабочий чат. Значения полей и тексты — в `index.html` (секция `#flow`), тайминги — в начале скрипта
- `hero-video.mp4`, `hero-poster.jpg`, `hero-video.js` — первый экран с видео: фон без звука; «Смотреть видео» показывает
  ролик целиком со звуком (выход — «Закрыть видео», Esc или конец ролика). Видео — копия 1280×720 исходника
  Sber_India_1920х1080 (86 МБ); для боевого сайта лучше отдавать его с видеохостинга или сжать сильнее
- `header.js` — шапка-стекло: над тёмными участками становится тёмной с белым текстом, над светлыми — светлой
- `services-bg.webp`, `request-bg.webp`, `hero-bg.webp` — фоны тёмных плашек
- `fonts/geologica-*.woff2` — Geologica (Google Fonts, лицензия OFL)

Просмотр: `python3 -m http.server 8766` в этой папке, затем http://localhost:8766
