# Копия лендинга rabota-landing-poc (вариант editorial)

Источник: https://rabota-landing-poc.vercel.app/?variant=editorial (снято 2026-10-16)

- `index.html` — статичная разметка страницы, отформатирована для правки
- `styles.css` — все стили (из сборки сайта, минифицированы; в конце добавлено правило для `[hidden]`)
- `script.js` — интерактив: вкладки, шаги, отрасли, FAQ, разбор запроса, окно заявки.
  Тексты лежат в `index.html`. Заявка никуда не отправляется, пока не задан `LEAD_ENDPOINT` в начале скрипта
- `hero.webp`, `favicon.svg`, `fonts/` — картинки и шрифт Commissioner
- `privacy.html` — страница «Данные в прототипе»
- `original/` — исходная сборка Vite/React как есть (интерактивная, но JS минифицирован;
  отправляет события и запросы на бэкенд Convex оригинального сайта)

Разбор запроса работает по правилам из оригинала, прямо в браузере, без сервера.

Просмотр: `python3 -m http.server 8765` в этой папке, затем http://localhost:8765
