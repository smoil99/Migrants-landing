# Лендинг «Специалисты из Индии для бизнеса — Работа.ру»

Статичный прототип лендинга (HTML + CSS + чистый JS, без сборки и зависимостей).
Репозиторий: https://github.com/smoil99/Migrants-landing (ветка `main`, пуш по SSH).
Хостинг: Render, Static Site, Publish Directory = `site-reg`, Build Command пустой.

## Где что лежит

- `site-reg/` — **актуальная версия, все правки вносить сюда.**
  - `index.html` — вся разметка.
  - `styles.css` — базовые стили из исходного сайта (сетка, адаптив). Не трогать без нужды.
  - `theme-reg.css` — тема и все доработки. Новые правила дописываются **в конец файла**
    с комментарием на русском, что и зачем. Цвета — переменные `--reg-*` в начале файла.
  - `script.js` — FAQ, мобильное меню, окно заявки (`data-action="lead"`), фильтры.
  - `flow-demo.js` — блок «5 шагов» в структуре галереи CleanShot: > 1024px — вертикальные вкладки слева
    (с полосой прогресса) и окно-демо справа; ≤ 1024px — слайдер из 5 карточек, в каждой своя копия окна
    (`createDemo`), активная проигрывает свой этап по кругу. Шаг 1 — режим «Загрузить файл» выбран сразу,
    курсор приносит файл из-за края окна и перетаскивает его в зону загрузки; поля — скелетон (`SKELETON`),
    затем заполняются (`FORM_FILL`), прокрутка, клик по «Отправить заявку», окно «Готово». Шаги 2–5 — экраны
    личного кабинета по макетам Figma (`.fs-screen`, тексты в `index.html`): список кандидатов → карточка
    кандидата с «Одобрить» → услуги «Начать/Завершить» → чек-лист «Вышел на работу». В начале каждого шага
    элементы экрана появляются по очереди (`intro`, `INTRO_GAP`); модалка «Готово» шага 1 — `SENT_HOLD`.
    Раскладка экранов — container queries по ширине окна (`.flow-window`).
    Тайминги в начале файла; описания этапов — во вкладках в `index.html`.
  - `hero-video.js` — видео первого экрана и режим «Смотреть видео» (прячет шапку, звук, Esc).
  - `header.js` — шапка-стекло: класс `.is-dark` над тёмными секциями (список селекторов `DARK`).
  - `counter.js` — счётчик `data-count` (анимация «25+» за 1 с).
  - `reveal.js` — появление блоков при прокрутке. Блоки (заголовки, тексты, карточки, кнопки, плашки с фоном)
    находятся автоматически во всех секциях `<main>` и в подвале — новые секции получают анимацию сами;
    исключить элемент — атрибут `data-no-reveal`. Стили — `.rv`, `.rv-in` в конце `theme-reg.css`.
    Внутри горизонтальных лент блоки только проявляются (`.rv-fade`), а у лент `overflow-y: hidden` —
    иначе сдвинутая карточка делала ленту прокручиваемой по вертикали и колёсико «залипало».
  - `features/` — иллюстрации блока «Шесть направлений» (из Figma, файл Migrants).
  - Фоны: `hero-video.mp4` + `hero-poster.jpg`, `fit-bg.webp`, `flow-bg.webp` (#why и десктоп «5 шагов»), `why-bg.webp` (не используется), `request-bg.webp`, `services-bg.webp`.
- `site/` — исходная статичная копия rabota-landing-poc.vercel.app без темы (для сравнения).

## Порядок секций (site-reg)

1. `#top` — первый экран: видео во весь viewport, текст по центру, «Смотреть видео» + «Получить КП».
2. Белая секция, наезжающая на видео при прокрутке: `#fit` «Подойдёт ли решение…» (карточки в стиле CleanShot: тёмная «25+» + две светлые со стеклянными чипсами).
3. `#why` «Люди и навыки под задачи предприятия» (тёмный фон-картинка `flow-bg.webp`, `cover`).
4. `#flow` «Пять этапов — от задачи до работы команды» (демо: форма заявки + экраны кабинета; десктоп — вкладки слева, ≤ 1024px — слайдер карточек).
5. `#uslugi-all` «Шесть направлений работы» (тёмная секция, карточки из Figma, общая grid-сетка).
6. `#replacement` «Возможность бесплатной замены» (светлая карточка + стеклянные чипсы).
7. `#methods` «Четыре способа привлечения» — тёмная плашка в стиле `#why` (фон `flow-bg.webp`), карточки-стекло лентой со стрелками как на reg.ru, «Что важно учитывать» — аккордеон `<details>`. Под ней отдельно плашка «Не уверены в способе?».
8. `#examples` «Примеры задач для специалистов» — слайдер карточек как у CleanShot (`.ex-*`): пастельные градиенты поверх фото отрасли (`examples/*.webp`, проступает сверху), стеклянные чипсы `.cs-glass`; стрелки — `initSlider` в `script.js`.
9. `#faq`.

Секция «Роли сторон» (`#roles`) удалена.

Тексты взяты с https://rabota-landing-v2.vercel.app/ (кроме названий вкладок «5 шагов» — оставлены прежние).

## Стиль и договорённости

- Шрифт Geologica (локально в `fonts/`). Акцентный цвет `#11D5CB` (`--reg-accent`), в т.ч. для ссылок.
- Кнопки первого экрана и шапки — «таблетки» (`border-radius: 999px`); «Получить КП» в шапке всегда бирюзовая.
- Кнопка-стекло с бегущим лучом — класс `.beam-button` (+ пустой `<span class="beam-halo">` внутри).
- Тёмные плашки с переходом в зелёный — класс `.contact-section` (используется в «Не уверены в способе?»).
- Стеклянные чипсы — `.cs-glass`, `.cs-row`, `.cs-chips`.
- Шапка закреплена и прозрачная (стекло); меню из 7 пунктов, на ширине ≤ 1280px прячется в ☰.
- Проверять правки на ширинах 1280, 700 и 390 px.

## Запуск локально

```bash
cd site-reg && python3 -m http.server 8766
```
→ http://localhost:8766

## Открытые вопросы

- `hero-video.mp4` весит 82 МБ (копия 720p исходника 204 МБ) — для Render лучше сжать до 5–15 МБ или вынести на видеохостинг.
- Экраны шагов 2–5 блока «5 шагов» с выдуманными данными (кандидаты, услуги, чек-лист, сценарий «120 сварщиков в Туле») — сверить с реальным процессом.
- Иллюстрации в `features/` — из графической библиотеки Авито (ims.avito.ru); перед публикацией уточнить права.
- `features/logistics.svg` весит 2,8 МБ (внутри встроенный PNG) — лучше экспортировать в WebP.
- Заявки никуда не отправляются: адрес обработчика — `LEAD_ENDPOINT` в начале `script.js`.
